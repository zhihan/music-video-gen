# Music Video Generator (MVG) - Architecture Plan

## Overview
A CLI-based tool to create video content from idea to final render using AI agents and Google Veo 3.

**Pipeline:**
1. **Script Creation** → User creates `script.yaml` with scenes, prompts, and timing
2. **Veo Generation** → Generate video clips via Google Veo 3 API
3. **Claude Code Assembly** → Interactively generate/tweak MoviePy scripts → Final video

## Features
1.  **Script-Driven Workflow:** Start with a `script.yaml` defining scenes and prompts
2.  **Claude Code Assembly:** Interactive MoviePy script generation with visual feedback loop
3.  **Multi-Format:** Support for Vertical (9:16) and Horizontal (16:9)
4.  **Manifest-Driven:** Uses `script.yaml` as source of truth for scenes, timing, and prompts
5.  **Iterative Refinement:** Claude tweaks assembly scripts based on rendered output
6.  **Audio Sync:** Loops video or cuts audio to match durations
7.  **Lyrics Engine:** Auto-transcribe via OpenAI Whisper & burn subtitles
8.  **AI Generation:** Direct integration with **Google Veo 3 API** to generate clips from prompts
9.  **CLI Interface:** Personal tool, command-line driven

## CLI Usage
```bash
# All commands default to script.yaml and can be overridden with --script

# 1. Create script.yaml manually with scene definitions (see example below)

# 2. Check project status
video-maker status
video-maker status --script custom.yaml

# 3. Generate a character reference image (for consistency across scenes)
video-maker imagen "12-year-old Asian girl with short black hair, school uniform" -o assets/character.png

# 4. Generate video clips via Veo 3 (with optional character reference)
video-maker veo
video-maker veo --reference assets/character.png   # Use character image for consistency
video-maker veo --script custom.yaml --output clips/

# 5. Generate a MoviePy assembly script with text overlays
video-maker generate-script
video-maker generate-script --clips ./clips --output scripts/assembly.py

# 6. Run the generated script, then refine with Claude
python scripts/assembly.py
# "The text on scene 3 is too small, make it larger"
# "Move the overlay up, it's covering the subject's face"
# Claude refines the MoviePy script and re-runs it.
```

## Implementation Notes

### Veo Integration
- Google Veo 3 via Vertex AI
- Scene prompts → video clips
- Handles aspect ratio, duration, quality settings
- Supports character reference images via Imagen

### Assembly (Claude Code-Driven)
Rather than a fixed automated pipeline, assembly is handled interactively by Claude Code:

**Workflow:**
1. User asks Claude to assemble video from `script.yaml`
2. Claude reads the manifest and generates a MoviePy assembly script
3. Claude runs the script to produce output (or a preview frame)
4. User reviews and requests adjustments ("text too small", "move overlay up")
5. Claude refines the script and re-runs
6. Final script saved to `scripts/` for reproducibility

**Why this approach:**
- Text sizing/positioning requires visual judgment - impossible to fully automate
- Every video has unique edge cases (face positions, varying text lengths)
- Personal tool = embrace iteration over over-engineering
- Claude can see rendered output and adjust, closing the feedback loop

**What Claude handles:**
- Clip concatenation with proper resizing/cropping
- Text overlays with appropriate sizing and positioning
- Audio sync (loop video or trim audio)
- Aspect ratio handling (9:16 vs 16:9)

## Code Style

Follow the [Google Python Style Guide](https://google.github.io/styleguide/pyguide.html).

Key points:
- Use `snake_case` for functions/variables, `PascalCase` for classes
- Use type annotations for function signatures
- Use docstrings with Google-style format (`Args:`, `Returns:`, `Raises:`)
- Max line length: 80 characters
- Use `from __future__ import annotations` for forward references
- Imports: stdlib, blank line, third-party, blank line, local. Alphabetized within each group.
- Avoid mutable default arguments (use `None` + assignment in body)

## MoviePy Style Guide

### Text Overlays
- No outlines/strokes, use semi-transparent background (`bg_color`) for readability
- When using `method='caption'` with TextClip:
  - Always specify explicit height in `size=(width, height)` - auto height `(width, None)` clips text
  - Use `vertical_align='top'` to position text correctly within the bounding box
- When adding audio to MP4: must specify `audio_codec="aac"` in `write_videofile()`

### Text Presets

Use these three presets (defined in `src/mvg/editor/overlays.py`) for all text overlays.
Word wrapping is handled automatically via `textwrap.wrap()` — no manual line breaks needed.

```python
TEXT_WIDTH = 680
TEXT_BG = '#000000AA'

# Presets: font_size, chars_per_line (CPL), max_lines
PRESETS = {
    "title":    {"font_size": 70, "chars_per_line": 17, "max_lines": 2},
    "text":     {"font_size": 50, "chars_per_line": 24, "max_lines": 5},
    "subtitle": {"font_size": 40, "chars_per_line": 30, "max_lines": 3},
}

# Text height formula: int(font_size * 1.4) * line_count + int(font_size * 0.3)
```

Set `overlay_style` in `script.yaml` scenes to choose a preset (defaults to `"text"`).
